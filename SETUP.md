# Setup (2 minutes)

1. On GitHub create a **public** repo named exactly your username (e.g. `asad-ali/asad-ali`). Tick "Add a README".
2. Upload these files to it: `README.md` and the `.github` folder (keep the folder path).
3. Open `README.md`, replace every `YOUR-USERNAME`, plus the LinkedIn, website and email links.
4. Repo -> Settings -> Actions -> General -> Workflow permissions -> choose **Read and write permissions** -> Save.
5. Repo -> Actions -> "Generate contribution snake" -> **Run workflow**. After ~1 minute the snake shows on your profile.
6. Optional: for the metrics card create a token (Settings -> Developer settings -> Personal access tokens) and save it as repo secret `METRICS_TOKEN`. Without it that workflow simply skips.
